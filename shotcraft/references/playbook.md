# 硬定式与返工判例

**每一条背后都有一次被判回来的返工。** 编号有空号——**只作废不重排**，留号存判例。

## 零、先看懂标杆片好在哪

别凭印象说「这片子高级」。拿工具逐帧抽出来对读，你会发现两支好片的配方是同一个：

**镜头持续行进 + 局部微事件链。**

- 页面立成 3D 斜墙，相机全程滑行不停；卡片随镜头经过**逐个亮色弹起**；文字信息长在墙上，不是浮在画面前。
- 开场 3 秒里：字标溶出 → 整页满幅入场 → 光斑三个 waypoint 游走 → 光池收拢 + 暗角加深 → 相机 16 帧推近 + 转 y 轴 → 主角卡弹簧离页悬停 → 3D 空间注记 → 压弹归位。

**没有一帧是「摆好等口播」。** 运动本身就是内容。

## 一、硬定式

**1. 整屏只干一件事**

要么一屏大字/动效，要么一屏铺满内容 + 运镜。**常驻件设白名单**（详见 `house-rules.md` 第三节）——三条常驻带一起吃掉内容区是最经典的病根。

**2. 长时间画面无新事件＝返工信号**

抽帧时相邻帧雷同就是证据。**「多久算长」不定机器阈值**——逐镜硬规交给模型自判，判断力归施工自查与看片。我们退役过两件量具（密度探针、运动守卫）就是因为阈值定不准，定了反而挡住合理的长停。

**3. 标签/数据进 3D 场景**

底部药丸、底边小字一律改成**页面空间注记**（大衬线字 + 数字滚动 + 马克笔高亮 + 软影 + 微幅浮动，透视随卡走）。

**4. 聚光会游走，绝不定点**

光池中心透明度压住（糊住文字即废）。定点光斑是白斑判例的来路。

**5. 素材必须全页 2x 真截图**

headless 浏览器，viewport 宽一点、`deviceScaleFactor: 2`、`fullPage`，采集时摘掉页头页脚 DOM。**窗口大小的壳截图是「没肉」的病根**——素材本身信息量不够，后面怎么运镜都救不回来。

**6. 照抄 demo 源码参数**

动每处之前先 Read **卡文「参考实现」指向的那份源码全文**。缓动、时值、位移、**含相机**逐值搬。

**「差不多」＝样式漂移＝返工。** 不要自造第二套相机判据去重写 demo 参数。

**8. 合规蒙版口径**

纹理里的 URL、外站名用页面同色矩形盖章。README 正文段落里的既有提及可以留（那是原文，不是你的导流），但巡礼路径 + 景深让它只在虚焦区掠过。

**自绘窗口件零地址栏、零页签条、零锁图标**——合法形态只到「标题条 + 三个圆点」。

星标数一类以截图为准，口播用模糊口径兜底。

**9. 音效钉帧表，时间线一动全表重钉**

帧位一律写成 `帧表.<场景>.from + n` 的**相对式**。连发音效阶梯递减；强鼓点 BGM 段音效克制；**先锁画面后钉音**。

时间线一动，**全表重钉，别手改单条**。

**11. 分镜层禁静态思维**

分镜每处必须写清「镜头怎么动」。写成「展示 X 画面」就是静态思维——只换素材不动版面，是返工头号病根。

**用「扫过／斜扫／横扫／光扫」这类具体运镜动词，别用「扫描」这类静态词。**

⚠️ 「写了动词但其实不动」（假推）**机器管不到**，从来都要人判。

**12. 主题级拍板必须样帧验证**

风格级方向决策先渲 1–2 张样帧给人看再定。**口头描述拍板＝整轮白做。**

**13. 数字件渲后逐帧核值**

计数器、数位滚动渲完抽帧逐位读数，对实测记录里的真值。旧素材里的过期数字用同色蒙版盖掉——**绝不伪造数字**（我们栽过一次显示值和真值差了 35 的判例）。

**14. 录屏底部动态带 vs 字幕位＝不挪位**

录屏素材自带底部动态区间时，字幕**不挪位、不额外加底**。可读性由字幕自带的胶囊底承担——胶囊在乱底子上比全局光晕更稳。

**15. 竖版分支与横版同步清扫**

双画幅共用组件里横版已裁掉的件，竖版分支必须同步清。**补渲竖版前先列一份「横版已裁件清单」逐一查竖版分支。**

**16. 失败版必留接触表**

中间版母带可以删，**删前必出一张与标杆并排的接触表**归档。

**增量判例：任何重渲动工前先归档当前版接触表**——重渲会原地覆盖母带，等你发现要对照时已经没了。

留档是有复利的：有一次返工前母带碰巧还在，才拿到「同时长同口播、只差视觉执行」的对照组，量出静帧占比 21.5% vs 0% 这条判据。

**17. 每屏至少一次定向引导**

真截图/真录屏段，**光标移到口播此刻正在说的那个东西上**，接一次点击脉冲或圈选，**替代「摆一张截图等口播」的裸静帧**。

这是**内容层运动，不是运镜**，与落定纪律不冲突——光标定向骑在相机弧上，两者叠加。引导落点与口播**同物**。

组件不合用的镜位用别的手段满足「每屏 ≥1 次」（圈选／高亮／局部推近），**别退回裸静帧**。

**18. A/B 双轨语义路由**

口播**逐句先过语义分类、再按类路由到视觉语域**，浅深交替成呼吸。

这一条治的是「太 PPT 了」的**另一半**根因：镜头密度治的是「切几刀」，语义路由治的是「每刀切出来还是同一种画面」。

**20. 开场包形态定式**

从自家跑得最好的那一期上逐帧量出来的形态（n=1，**形态对照不是因果**，所以立定式不立闸，例外写理由）：

- 第 0 帧就是货，禁字标、禁品牌开场卡、禁静帧——暂停第 0 帧要能认出「这是什么」。
- **成品轨不断**，不切安装、不切聊天、不切 logo。
- 静默只许一处（表演气口），短。再现更长的无口播段就是打回。
- 只给能力不给完成——录音只放 0.4s 波形不播完整回放，成片最后一镜留给主体。
- **片头用过的镜头，主体不原样重播**（重播＝告诉还在看的人「后面没新的」）。

**21. 镜头层定式**

回执逐镜表**必带「镜头层」列**：每镜写卡名／起止帧／落定帧，静幅镜写 `STILL:<理由>`，证据镜写取景键。

⚠️ 反证追注：**逐镜数值硬表会架空判断层**。我们写过 31 行逐镜相机表，结果 14 个证据窗被推到 1.18–1.45，真截图裁字、并排失效、露底。**给约束，不给数值。**

**22. 按叙事任务选卡，空间语法先行**

首版病根＝**选卡匹配了数据类型，没匹配叙事任务**。那一期卡名零机械复用、契约全过，但扫描／打字机／逐行嵌入／柱图／数位滚动全属「二维信息进入容器」同一种语法：正视、平面、矩形、落定后静止——连续播放就是 PPT。

**卡片去重 ≠ 审美去重。机器读数证明不了这件事。**

五条选卡口径：

1. **逐镜先答「这一镜要让观众理解什么」再选卡**。开场答「第一眼记住什么」，不能只负责展示证据。
2. **说明段拆三层**：真截图当证据层、中文卡当主叙事层、结论落定。英文原文不承担主阅读（**层级问题，不是语种问题**）。
3. **多维指标优先表达维度间的关系与合成结果**，不默认平铺行卡或柱图。
4. **关键比较镜要把比较关系空间化**——只让两个数字滚动不算完成比较叙事。
5. **高能相机卡全片限量**，留给反转／揭晓／章节峰值；普通解释段用稳定视差与逐站聚焦。匀速循环轮播类卡不当主解释镜——无起点无落定，信息一直从观众面前经过，反而难读。

开工前另有四项**空间语法前置**：空间母题／主材质／主光源／摄影机性格。缺任一项不进逐镜施工。

## 二、复发判例：缺的不是规则，是没有机器面守着它

有一期独立终检抓出 20 条，其中三条对应的规则**开工前就在册**，仍被逐条违掉：

| 规则 | 复发 | 实测 |
|---|---|---|
| 「谁是谁，对照物标识分得清」 | 第 2 次 | 全片 105s，两个被测产品的名称/图标 **0 镜 0 秒**；唯一产品标识是输入框角上 27px 的一个字，约 7 秒。两条线在画面上唯一的区别是「左边有编号」 |
| 「英文界面不上满屏」 | 第 2 次 | 两镜背靠背 13.7s 讲同一批 33 个英文文件名；单帧英文卡横跨整幅画宽，除字幕外全屏无中文 |
| 「相机落定 / 自报可信度」 | 第 2 次 | 一镜自报「有运动」+ 卡名，实测连续 139 帧（4.63s）内容层零变化——全片最长死画面 |

**再补一条同义规则正是「药在库里没被翻开」那个病型。** 该做的是补闸，不是补文字。

而补闸有它自己的纪律：**要设计、要跑正负对照、别跟日更同一晚上线**。我们有过新闸当天上线、当天就在真件上判反的判例。

## 三、给下一期的固定动作

- **上一轮的判词逐字进下一期派工单**，别转述。
- **自报值不许当读数用**：要么现量，要么标「自报未验」。
- **每期首验件 ≤2 件**。一次验太多，哪条起作用分不出来。
- **别拿单期成功写正本**。至少三期。
