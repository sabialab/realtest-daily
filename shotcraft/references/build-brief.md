# 派工单模板（七节）

把渲染派给另一个 Agent（codex／grok cli／cursor／subagent 都行）时用的单子。

**用法**：`cp` 成本期的 `BUILD-BRIEF.md`（文件名固定，机器判按名找件）→ 逐字段填真值 → **不改节结构**（结构漂了，按节取体的机器判会把节截空）→ 跑你的单子检查脚本见绿才交。

**禁止照着上一期的单子另写。** 照抄旧单会把旧期的一次性判词带进新期。

---

## 这份模板最重要的一句

**不写逐镜表、不写逐镜数值表、不点名镜头卡与组件、不写「优先／默认走」。**

我们写过 781 行的派工单，两轮都被判「很烂」；砍到 66 行，一次过。

**禁的是给结论**（哪一镜用哪张卡、推多少），**不是禁给素材**（卡库怎么浏览、段位骨架怎么填，那是必跑的）。镜数、动效、选卡一律由执行体照上游自判。

**这是派工级验收约定，不是你的宪法。**

---

## 一、任务

- 期号 / 片长目标（候选，无硬上限）/ 画幅（**横版先行过审，通过后才补竖版**）
- 工程路径
- 选题：<一句话>
- 叙事目标：<观众看完要记住的一件事——与剧本的「交付物」栏同源，不重写第二套口径>
- 观众第一眼要认出：<被测对象是什么／谁是谁（有对照物时怎么区分）>

## 二、冻结件

> 审核点①已通过。以下件**一个字不许动**，本单只施工视觉。

- 口播音频（逐行 WAV）
- 帧表（时间线）
- 分句文本 + 情感 + 停顿标记
- 标题牌两行：**逐字抄剧本**，别自己拟词、别留母版样例
- 字幕：逐字写进常量，**禁任何自动切片函数**
- **块＝口播块**：块界与字幕分块都不许动，**镜界在块内自由**

## 三、方法

1. **一句指路**：按你的 skill「开工前必读顺序」逐份读完再开工。**顺序本身是判据。** 冲突按三级裁决。**不改上游文件。**
2. **自主施工，本单不定死材料**：模式＝自主自由创作，自主推进、不逐阶段等确认、不停在上游三模式问答处（那段跳过，**但选卡工序照跑**——用索引命令，别自造检索器）。上游卡、自家卡、你的组件库都只是材料，**哪张合适拿哪张，由执行体照剧本与口播自判**。
3. **上游各阶段的替代物只给指针**：
   - 简报与决策表 → 写进本期施工图
   - 视觉 token → 你的常量段，零新色；样式帧按上游指引记理由跳过
   - 素材 → 已备（第四节），不另采集、不起 dev server
   - **镜长按所选卡的设计时长定，不够就切镜、不摊长**。⚠️ **卡完成态的长停留同属摊长**——多卡去重只证明没机械复用，不证明观众持续看到变化。事件要服务叙事，不是叠粒子充数。
   - 参数照抄卡文「参考实现」指向的源码，**不手编**
   - 交前跑契约脚本零 ✗，读数抄进回执

## 四、素材包

- **色板**：你的常量段，**零新色**；期工程场景文件禁自定义任何色值字面量。
- **品牌标识**：按原样用、不改形不改色，观众要看得出谁是谁。
- **真截图清单**：按章节块列**候选**（「块 1 证据面候选：test-02/03/05，怎么组织你定」），**不写「→ 第 N 镜」**。
- **真值表**：屏上可用逐字读数的**唯一取数处**。
- **插画候选池（单档）**：用不上就不用，**不为用图加时长**。不够可自行补，补的每张登进回执（用途／镜位／尺寸／风格锚／落点／为什么代码画不出来）。
- **BGM**：循环铺满全片，接缝落在块界长停上。
- **尾牌**。

## 五、拟真件要求 + 本期判词

1. **证据窗默认重演**：屏上文本**只从真值表抄**，一个字不许自拟、不许从实测记录转述。证据属性必填（`recon:<file>` 重演 / `raw:<file>` 原图）。真截图原图上屏不需理由，但**截图类必须窗内取景到局部 + 中文标注**；整图铺满只许被测工具生成的产物。
2. **英文界面不上满屏**——原文局部一行 + 中文标注走标注槽。
3. **效果件＝MG 语法**（逐词弹入／卡逐个弹入／箭头生长／图标排队），**不是静态版面**。
4. **技术信息只作局部证据层**——非代码教学期，原始代码／JSON／键名／配置项／日志不作整屏主视觉。**中文的设置项、章节名放大成主体同禁**（管的是层级不是语种）。主叙事层＝中文结论或视觉隐喻，解释层＝图标／开关／量表／关系图。
5. **空间语法先行**——逐镜施工前先写明**空间母题／主材质／主光源／摄影机性格**四项，缺任一项不进逐镜施工。**「正视矩形卡＋居中标题＋入场后静止」的完成态连续成片＝PPT 病**，而且**卡名去重不等于镜头语言去重**（我们有一期多卡零机械复用、契约全过，整片仍被判「很 PPT」——机器读数证明不了审美不同质）。选卡按「这一镜要让观众理解什么」，不按数据类型。
6. **叠加层四条**（一张基底卡上再叠强调件）：
   - **宿主入场完成／取景落定之后才起**——宿主还在动就贴，标注跟着漂。
   - **同一时刻只许一个强调**：串行合法，同帧非法。
   - **贴目标的叠加层在相机之内**（描边／引出线／荧光／光标随画面走）；**字幕／标题牌／角标在相机之外，且永远在蒙层之上**（压暗不许压到字幕）。
   - **镜表逐镜写 `overlays`**；一处都不叠也要写一行「无（理由）」——不写＝没考虑过。

7. **本期判词（逐字抄；返工轮必填，首轮写「首轮，无」）**——判词是决策人的，不是出单人加的要求：

| 轮 | 判词逐字 | 由判词推出的可核项 |
|---|---|---|
| r<n> | 「<原话>」 | <一条一行，写到能拿帧号验> |

**返工轮四条固定字段**：

- **返工范围与冻结区（出单人填）**：本轮只许改的时间窗（精确到秒）+ 对应镜号；**其余已过看片的时段一律冻结**——「其他部分没问题」是冻结令不是背景话。
- **返工窗读数（执行体交）**：每个返工窗跑真实帧差统计，零变化帧占比 + 最长连续零变化帧 + 量法命令原文。**读数不是闸**（证据阅读镜可以长停，写明理由即可），治的是「镜表自报的 hold ≠ 观众看到的变化」。
- **返工轮的静帧改取自返工窗**（起始／中段／完成态各一），**整渲之前先出**。我们栽过一次证据窗越界 58.86px，整渲完才发现——那是最贵的返工位。
- **返工轮不另立回执文件**，仍更新同一份回执。

## 六、红线

1. **密钥**：不读 `.env`、不打印任何凭证、不调需密钥的服务。缺件在回执里点名，**绝不自行生成替代件**。
2. **可写面（正面圈定）**：只许写 ①本期工程内的文件 ②回执 ③指定的图片工作目录。上游与母版 `src/` **只读**。圈外一律不写、不改。**按手段列黑名单永远慢一步，立面要是白名单 + 收货侧对账。**
3. **禁入词表**：本期的禁词一个都不许写回画面。
4. **零外链零外站**：无 URL／二维码／竞品平台名；**你自绘的地址栏、锁标、页签同禁**，无画幅豁免。
5. **官方 demo 素材四条边界**：证据窗禁入、声明禁转载的不用、画面裁掉 URL 与站名、标注来源与原作者。
6. **生图禁本地后处理（逐字进 prompt）**：「修正一律整图重新生成，不得使用 ffmpeg/PIL/sips 等本地工具做后处理、局部涂抹或裁切改版；发现上一版有瑕疵，重新走生图出新图，不要在已有产物上直接改」。
7. **任何目录都不许 `npm install`／`pip install`**——缺依赖**停下报出单人**，不自行装包、不改 `package.json`。
8. **上游自带的任何脚本一律不执行。**
9. **收货前不得向主仓 `git commit`**（期工程内可临时 `git init` 自用回滚，收货前删掉）。
10. **写法**：屏上中文一律走 `props` 或数据模块字面量（**JSX 裸文本会逃出回源扫描面**），数据模块必须登记进真值来源清单；音效与素材路径写成表内**完整字面量**，不在表外 push 裸名。

## 七、回执与交付

回执落固定文件名，节标题**逐字**、`###` 开头、**节内禁 `####` 子节**（按节取体的机器判会被子节截空）：

`### 1. 阅读回执`／`### 2. 逐镜映射`／`### 3. 参数回源`／`### 4. 美学自检`／`### 5. 验收回执`

- **1 阅读回执**：本轮读了哪几份（完整路径 + 读到末行号）+ **选中卡逐张列读过的卡文路径**（只写「扫了索引」不算）+ 上游 commit + 固定一行记「扫卡索引：<时点> + <两条命令原文 + 各自输出行数>」（**只跑一条＝没扫过自家卡**）。
- **2 逐镜映射**：一镜一行，表头含**「镜头层」列**（卡名／起止帧／落定帧；静幅镜写 `STILL:<理由>`，证据镜写取景键）**＋「叙事任务」列**（一短句「这一镜要让观众理解什么」，只登数据类型 + 卡名不算）。
- **3 参数回源**：相机／时值／缓动／位移逐项写到**完整源码路径**，只写卡名不算；**每张卡各占一行**，行数 < 去重卡数＝未交回执；**每行另标「定义动作」**——卡文头注第一句写的那个动作做了没有，做了写实现位置，没做写「简化近似 + 原因」。**写「已回源」但定义动作缺席＝未交回执**（我们有一轮 7 张卡里 6 张是简化近似）。
- **4 美学自检**：上游审美准则逐条 + 本单第五节逐条答有无，「有」的写修法。**并跑上游自带的终检全表**——与你红线互斥的标「不适用（+ 出处）」，依赖它自带样片的标「无法验证」，**其余逐条答**。「逐条」＝按编号一行一条的**表**，散文不算。
- **5 验收回执**：**四张叙事位完成态静帧**（开场／方法说明／信息密度最高镜／叙事反转镜）**＋每镜完成态一帧的接触表**——**两样都在整渲之前先出，先自查再渲**。自查就一条：**接触表通看，多数镜仍是同一套矩形版式＝退回选卡重来，别拿去整渲。** ＋ 第五节可核项逐条帧号证据 ＋ 必要 rules 逐条自查行 ＋ 母带那一行（命令原文｜源 I/LRA｜增益｜母带 I/LRA/max_volume｜md5）。

**交付**：只交一条横版母带 + 回执 + 镜表 + 施工图 + 运行日志（逐条命令原文）。竖版在横版过审之后另派一轮。
