# 施工图骨架（REBUILD-SPEC）

复制成本期工程根目录的 `REBUILD-SPEC.md`，由执行体自建自填。**逐字段填，不改节结构。**

⚠️ 期工程根目录出现与方法正本同名的 md ＝ FAIL。**方法正本只有一份，别让它被 `cp -R` 冻成第二份。**

## 〇、空间语法前置（缺任一项不进逐镜施工）

- **空间母题**：<这支片的世界长什么样，一句话>
- **主材质**：<纸／玻璃／金属／墨，一句话>
- **主光源**：<从哪来、什么色温、硬还是软>
- **摄影机性格**：<稳重旁观／贴身跟随／悬浮巡礼>

## 三、逐场施工

每场**四件套 + 第五件套**：

| 件 | 写什么 |
|---|---|
| ① 挂载帧窗 | `W.<场景>` ＝ 起帧–止帧 |
| ② 换件 | 这一场换掉了哪些素材/组件 |
| ③ 音效钉帧 | 相对式 `W.<场景>.from + n` |
| ④ 竖版分支 | 竖版这一场有什么不同 |
| ⑤ 卡与理由 | 用了哪张卡、为什么、备选是哪张、为什么没用它 |

### 每场的标准块

```markdown
### S〔n〕·〔场景件名〕（挂载 `W.〔scene〕` ＝〔起帧〕–〔止帧〕）

- 叙事任务：〔这一镜要让观众理解什么〕
- 卡：〔卡名〕｜备选：〔卡名〕（为什么没用它：一句）
- 镜头层：〔卡名／STILL:理由／keys〕
- 换件：〔…〕
- 音效：〔W.scene.from + n → 件名〕
- 竖版分支：〔…〕
```

### 槽位件

按语义填件名与帧窗。**不填的槽写「N/A ＋ 一句理由」，不许静默省略。**

## 四、`shots.json` 契约

一镜一条，机器判要能吃：

| 字段 | 说明 |
|---|---|
| `card` | 卡名。值域＝上游卡库 ∪ 自家卡文件名 ∪ `none:<≥4 字理由>` |
| `overlays[]` | 这一镜叠了哪几张强调卡（纯字符串数组，同值域，不含 `none:`）。一处都不叠也要写一行「无（理由）」 |
| `camera` | 镜头层。静幅镜写 `STILL:<理由>`（缺理由只 WARN），证据镜写取景键 |
| `kind` | `evidence` 一类由**定义体是否含证据锚反推，不靠自报** |
| `hold` | 落定后 hold 帧 |
| `feature` / `card_why` | 这一镜的功能、为什么选这张卡 |

### 契约脚本该判什么

- **一件一卡**：同一个组件对应同一张卡（WARN）
- **同一张内容卡重复 ≥N 次**（ERROR/WARN 分档）
- **`camera=keys` 的镜，其组件定义体必须真有取景键**
- **证据锚为内容的场景，同文件内禁套镜头层**（豁免按镜号点名，不许通配）
- **取景键必须是内联数组字面量**（`keys={someVar}` 判红——变量指过去的东西机器读不到）
- **落定判首尾不判相邻**：首尾缩放比与落定帧数各有上限
- **截图类无取景键、且不在「产物」目录前缀下 ⇒ 判红**

⚠️ 最后一条的设计要点：**判据要能反锚回源码**。`card` 字段一度是唯一没有源码反锚的字段，于是执行体自建了一个通用组件、把卡名当标签贴上去，机器一点感觉都没有。修法是让卡在源码里留下可 grep 的锚（`data-card="<卡名>"` 或注释行），契约脚本读锚不读自报。

## 五、验收（顺序不能换）

1. **接触表自查**（整渲之前）——多数镜仍是同一套矩形版式就退回选卡重来。**整渲后才发现是最贵的返工位。**
2. **契约脚本 + 全量复核**
3. **人判四项**：取景切正文／深底角标对比／卡片倾斜三面／画面单不单一
