# 自家卡怎么写

## 两类卡，两个正本

- **上游卡＝词汇**。正本永远在上游按需读：卡全文 + 卡文「参考实现」指向的源码，参数含相机照抄。
  **不做上游卡的镜像表。** 我们做过一份 106 卡适配层，升级一次全废，最后整体退役。想不起卡属哪类就 grep 上游目录。
- **自家卡＝语法**。每张都得有**返工判例、实测背书或第三方移植来源**。
  **只写选型、红线与判例，参数一律去组件头注读**——值不在两处存。

## 什么时候该写自家卡

**上游没有这个语法，而你反复需要它**——通常是被判回来两次以后。

自家卡分两类：

- **基底卡**：槽位内容件（证据窗、拟真 UI、知识卡轨、块界、尾牌）。可以落在任何段里。
- **叠加卡**（`层性: 叠加`）：贴在任一宿主上的强调层（描边／引出线／荧光／光标）。与段位正交。

⚠️ **开场／转场／峰值／功能爬升四段的镜头语法一律去上游选卡，自家卡不填这四段。**

这句禁的是「拿自家卡当**镜头语法**用」，不是禁你定死的**槽位件**——一个占的是「这一格该用哪种镜头语言」，另一个占的是「这一格放什么内容」。两件事。

## 卡文格式

```markdown
---
name: <卡名，＝文件名>
层性: 相机 | 内容 | 叠加
一句话: <这张卡到底在做什么，一句说完>
适用: <什么镜位用它>
时长: <区间>
能量: <低压升 / 中 / 峰值>
组件: <承载它的组件名>
---

## 意图
<为什么会有这张卡。写清它治的是什么病——最好直接写判例。>

## 做法
- 相机：<动作序列，不写数值>
- <内容层怎么动>
- <运动感的来源，鼓励用足哪几件>

## 组件与机器面
<组件在哪、几何常量去哪读（不自造数）、契约脚本怎么判它、读数行叫什么>

## 已知坑
- <被证伪的旧口径，写明「别照旧 spec 作废行施工」>
- <技术坑>
- <被判过「这不算缺陷」的，也写下来>
```

**frontmatter 是选卡时唯一会被扫的东西。** 写得含糊，这张卡就等于不存在。

## 示范卡（脱敏版）

```markdown
---
name: evidence-window-push
层性: 相机
一句话: 证据窗轨的唯一合法相机动作——硬切到区域 → 窗内微推 → 短促落定 → hold；运动感全部让给内容层
适用: 真截图/真录屏证据窗（日志、装机屏、输出屏、看板）
时长: 2.5–5s（落定后 hold ≥1s）
能量: 低压升
组件: EvidenceWindow
---

## 意图
证据窗是全片唯一被红线锁死「内容必须回源到真数据」的一格。它的任务是
**让人读清那几行字**，不是表演运镜。

有一轮我们给 14 个证据窗套了张力相机卡，推到 1.18–1.45——结果真截图裁字、
A-B 并排失效、露出背景底，判词是「证据框在飘，不如第一版」。本卡就是那次
返工的成文形态：**证据镜的相机几乎不动，动的是内容层。**

## 做法
- 相机：硬切到区域（第一个取景键）→ 窗内微推（首尾缩放比很小）→ 短促落定 → hold。
  **不套通用相机组件。**
- 内容零出画：窗框／标签／徽章／扫描线／文字每一帧完整在画幅内，不压标题牌下沿与字幕带。
- 运动感来源（鼓励用足）：光标一次定向点击、扫描线、标签弹立、快闪计数、点亮、滚数。
- 图在窗内：截图类一律走取景键（组件内 CSS `zoom`）；只有「产物」目录下的东西才整图铺满。

## 组件与机器面
窗容器组件必填证据属性（`raw:<file>` / `recon:<file>`）；几何常量去组件头注读，**不自造数**。
窗里的内容默认是拟真组件逐字重演（真值表 → 数据模块 → 回源脚本）。
契约：证据锚为内容的场景，同文件内禁套通用相机组件（豁免按镜号点名，不许通配）。
另有静态判：取景键必须是内联数组字面量；首尾缩放比与落定帧数各有上限（判首尾不判相邻）；
截图类无取景键且不在「产物」前缀下判红。

## 已知坑
- 「给证据镜一条完整相机弧」是被实证推翻的口径，**别照旧 spec 作废行施工**。
- `transform: scale` 放大真截图＝糊字（先按原尺寸栅格化再放大）。缩放一律走 CSS `zoom`。
- 光标件会在某几帧盖住屏上文字——这是拟真行为，不算缺陷。
- 光标坐标是画幅归一化，配取景键时要按落定键换算源图像素 → 屏位置，且**只在 hold 段落点**
  （微推段落点会漂）。
```

## 选卡的第一动作

**扫两处，不是一处。**

上游卡有它自己的索引（一条 `jq` 直读它的 `library.json`，别自造检索器）；**自家卡不在那份索引里**，得另跑一条 grep。

只跑第一条的后果：自家卡在「选卡第一动作」里完全不可见——写了也没人用。这是我们四路 review 同时指出来的断链。

**扫的是两处的全部 frontmatter，挑首选 + 备选。** 备选要写「真能换上的另一张」+ 一句为什么没用它。
