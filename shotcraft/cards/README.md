# cards/ — 自家卡

上游 152 张卡（`../upstream/references/shots/`）是**主词汇**；这里放的是上游没有、而我们反复需要的**语法**。

**只写选型、红线与判例，参数一律去组件头注读。** 值不在两处存。

## 两类

- **基底卡**：槽位内容件（证据窗、章节头、快闪、尾牌）。可以落在任何段里。
- **叠加卡**：贴在任一宿主上的强调层（描边／引出线／荧光／光标）。与段位正交。

⚠️ **开场／转场／峰值／功能爬升四段的镜头语法一律去上游选卡，自家卡不填这四段。**

禁的是「拿自家卡当**镜头语法**用」，不是禁槽位件——一个占的是「这一格该用哪种镜头语言」，另一个占的是「这一格放什么内容」。两件事。

## 选卡的第一动作：扫两处

```bash
# ① 上游 152 张
jq -r '.cards[] | "\(.category) | \(.name) | \(.use)"' ../upstream/gallery/api/library.json

# ② 自家卡——它们不在 library.json 里，得另跑一条
grep -H '^一句话:' *.md
```

**只跑第一条的后果**：自家卡在「选卡第一动作」里完全不可见——写了也没人用。这是四路 review 同时指出来的断链。

扫的是两处的**全部 frontmatter**，挑首选 + 备选。备选要写「真能换上的另一张」+ 一句为什么没用它。

## `shots.json.card` 的值域

上游 `library.json` 的 `cards[].name` ∪ `cards[].styles[].key` ∪ 本目录文件名（去 `.md`）∪ `none:<≥4 字理由>`。

`overlays[]` 同值域，但不含 `none:`。

## 写一张新卡

**通常是被判回来两次以后**才该写。格式：

```markdown
---
name: <卡名，＝文件名>
层性: 相机 | 基底 | 叠加
一句话: <这张卡到底在做什么，一句说完>
适用: <什么镜位用它>
时长: <区间>
能量: <低收 / 中 / 高>
组件: <承载它的组件名>
---

## 意图
<为什么会有这张卡。写清它治的是什么病——最好直接写判例。>

## 做法
- 相机：<动作序列，不写数值>
- <内容层怎么动>

## 组件与机器面
<组件在哪、几何常量去哪读、契约脚本怎么判它、读数行叫什么>

## 已知坑
- <被证伪的旧口径，写明「别照旧 spec 作废行施工」>
```

**frontmatter 是选卡时唯一会被扫的东西。写得含糊，这张卡就等于不存在。**

## 少了 11 张（说明一下）

我们实际在用的自家卡有 16 张，这里只有 5 张。

**另外 11 张是从 [video-talkcraft](https://github.com/Vincentwei1021/video-talkcraft) 移植的**（拟真 UI 剧场、玻璃代码走读、聚光压暗、荧光划重点、引出线标注、引文夹句、3D 页面倾斜、光标点击、终端打字机、发指令输入框、知识卡轨深色语法）。

那个上游是 **PolyForm Noncommercial 1.0.0**——非商业授权。把它的衍生件放进 Apache-2.0 仓，等于替上游把授权改成了商业可用，而踩坑的会是拿去商用的你。**所以这 11 张不在这儿。**

要用这几种语法：去 [video-talkcraft](https://github.com/Vincentwei1021/video-talkcraft) 看原卡，**自己确认授权覆不覆盖你的用途**。

移植时有两条读法值得说（这两条不涉及它的内容，是我们自己的经验）：

1. 它的卡**不在** `library.json` 里，值域靠目录文件名自动吸收。
2. **参数不在它的 demo 里，在你自己的组件头注里**——它的 demo 是另一套舞台尺寸和技术栈，像素和字号得按你的字阶重给，**demo 值一律不照抄**。
