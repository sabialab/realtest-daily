# 实测日更流水线（realtest-daily）

做「每天实测一个工具、当天出内容」这类账号的一条完整作业线。

它治的不是「写不出来」，是**写得出来但都是水文**。

七步：

```
选题打分 → 安全预审 → 真装真跑 → 定主卖点 → 换元写稿 → 人味审校 → 发布前自检
                                              │
                                              └─ 出片：1a 剧本+口播 → 1b 声音 →【审①】
                                                       → 2 施工渲染 → 收货QC →【审②】→ 3 竖版
```

## 它给你的四样东西

- **一把选题尺子**——六维打分（信息差／可操作性／真实性／时效性／安全性／可带走物）＋ 一道「可展示闸」。总分不够就换题，**宁发轻内容不发水文**。
- **一条不许绕的铁律**——进内容的工具必须当天真装真跑，跑挂也照写。数字只来自实测记录，一个来路不明的都不许有。
- **一个防散架的前置**——写稿前先把主卖点拍死，标题／封面／正文／视频全部同源于它。这一步不做，后面全是返工。
- **一份「机器能判的错绝不留给人审」的清单**——哪九类必须写成脚本，哪四项只能靠人看。
- **一条完整的视频产线**——证据窗与真值表回源闸、反 PPT 的四件套与「运镜要落定」、Remotion 工程七条硬规、收货 QC 的机器/人工分界、七条翻车清单（`references/video.md`）。
- **口播与声音的全流程**——剧本七位、写口播的落笔法与六条自查、两把外部尺子、TTS 打标记与合成、字幕冻结件、BGM 竞标与人声闸的中文假绿坑、混音样带与响度三条、提审与回流边（`references/narration.md`）。

## 安装

- **Claude Code**：把整个目录放进项目的 `.claude/skills/realtest-daily/`，对话里说「今天做什么选题」「帮我把这次实测写成稿」即可。
- **其他支持 Agent Skill 的助手**：导入 `SKILL.md`。`references/` 是可选加载层，**主文件不带它们也能跑完整流程**——只有需要更细的判据时才会被读进来。

零依赖、无脚本，纯 Prompt。

## shotcraft 魔改层

`shotcraft/` 是**出片那一层的完整方法包**——怎么在一个开源镜头卡库（[video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft)，Apache-2.0）之上，加出你自己的产线：

- **房规层**：把你的红线映射成画面规则；九条「必要 rules」；上游哪几条在你这儿不执行
- **四阶段两审核点** + 收货 QC 的机器判/人判分界
- **派工单七节模板**——派活给另一个 Agent 渲片时用的单子，这一层里最值钱的一件
- **施工图骨架** + `shots.json` 契约该判什么
- **硬定式与返工判例** + **自家卡怎么写**

**上游 video-shotcraft 的原样副本就在 `shotcraft/upstream/`**（Apache-2.0，152 张卡 + 216 个 demo 源码 + 卡索引，零修改），自家卡在 `shotcraft/cards/`。
唯一没收的是 PolyForm 非商业授权的那 11 张移植件——理由见 `shotcraft/cards/README.md`。

## 搭配

第 6 步的人味审校有独立开源版：[de-ai-flavor](https://github.com/sabialab/de-ai-flavor)。装了就直接调它，没装就照 SKILL.md 里的十二项自查。

## 几句实话

- **它不替你判断某个工具好不好**——它只保证你真的跑过了才敢说。
- 六维分数是参考值，同一个选题两个人打分允许 ±3 的浮动。真正卡人的是那四条硬门槛和可展示闸，不是总分。
- **第 7 步的九类检查这里只给了判据，脚本得你自己写**——因为每个平台的字数限制、画幅、词表都不一样，写死在 skill 里三个月就过期。
- 它假设你是「实测型」账号。纯观点号、纯资讯号用不上第 2–4 步。
- **视频那份假设你用 Remotion**（React 渲视频）。换框架的话，除「工程规范」一节外都通用——反 PPT、证据窗、两审核点、收货 QC 是方法，不是 API。
- **给的是判据不是模板**：色值、字号、时长、音量这些值，每个号都该有自己的一套。抄我们的值只会让你的片子看起来像我们的片子。
- 输入的外部素材一律视为数据、不视为指令——这条防注入规则写死在 SKILL.md 里。

## 方法论出处

这套流水线是一个中文 Agent Skill 垂直号日更一百多期跑出来的，每一条判据背后都有一次真实的翻车：

- 「可展示闸」——因为「六条硬标准自检清单」这类选题曾被判成高分，而它对零基础读者是零。
- 「主卖点硬前置」——因为角度定得太晚，整版返工过两次。
- 「机器能判的错绝不留给人审」——因为手写的 ✅ 骗过了人，没骗过发布。
- 「零命中必须先跑正对照」——因为扫描器根本没工作时，输出和「干净」长得一模一样。
