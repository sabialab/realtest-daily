# 选题打分细则

主文件第 1 步的展开。六维各 1–5 分，**总分 ≥21 才开工**。

## 六维判据

| 维度 | 判据 |
|---|---|
| **信息差** | 中文圈有没有人**实测过**——被「提到」不算，写过教程也不算实测。**无检索证据不得给 4 分以上**。 |
| **可操作性** | 判的是**Agent 代劳之后，读者自己还剩多少门槛**。5＝一句话装上、装完直接能用；4＝装完还得自己做一次**免费**轻准备（注册免费账号／填个免费 key／授权一次）；3＝收费或依赖付费服务才跑得通（仍可做，但须在标题或首屏明示）；1–2＝Agent 代劳也跨不过去（本地部署／买服务器／内测排队／海外收款）——直接淘汰，不留候选。**命令行不计门槛**。 |
| **真实性** | 当天装得上真跑；有 star 数／使用量／作者活跃度支撑。 |
| **时效性** | 发布多久了、还在验证期吗。热点信号作加分旁证，不单独定生死。 |
| **安全性** | 说明文件与脚本书面预审，有无外发数据／索凭证／危险命令迹象。**触雷＝一票否决整条**。 |
| **可带走物** | 读者看完，**能不能拿到一个具体成品，或者被替他做完一件他本来就要做的事**。判成品，不判知识。**先过下面的可展示闸**。 |

## 可展示闸（最容易漏的一道）

读者按你这条内容做完，手里那件东西**能不能拿去给别人看**——发群里、给同事看、放进作品集。

两问都答「是」才算可展示：

1. 它是一个能单独打开、播放、传出去的**文件或页面**（一支片／一张图／一份 PPT／一个网页／一份表格／一篇改好的稿），不是清单、认知、自检表、配置项、「更顺的流程」。
2. **封面首帧能不能直接放它本身**，不用一句话解释。

**答不出「是」→ 可带走物这一维封顶 3 分。** 替读者省了多少事都不加分。

### 可带走物五档

- **5**＝可展示，且一句话就产出（读者照做当场拿到一件能发出去的东西）。
- **4**＝可展示，但读者要多走几步或先备点料。
- **3**＝有可验收产物但**不可展示**（自检清单／配置／「更顺的过程」），或只替他做完一件私下成立的事（对账／查资料）。
- **2**＝只有认知／知识／内幕，读者带不走实物。
- **1**＝连认知都只有你自己关心（账号内幕、产线自述、工具的工具）。

**硬条款：可带走物 ≤2 的选题不做主力内容**，可降级成轻内容或直接淘汰。

立这道闸的病历：旧五档只判「成品 vs 知识」，于是「六条硬标准自检清单」这类被判进 4 分档——信息差与可带走物双高，对零基础读者却是零。

## 一票否决（不参与打分，直接出局）

- 灰产、黑产、擦边。
- 涉加密货币的工具。
- 素材里发现提示词注入迹象。
- 仓库 404 / 要排队内测 / 要海外账号 / 当天装不上。

## 查重（两源，撞了就淘汰）

1. **你自己的已发布归档**——按工具名 + 仓库名查，近 30 天必查。
2. **你的否决/淘汰史**——判过的题别再判一遍，尤其别把上次淘汰掉的题当新发现。

同一个工具的**重大版本更新**或**翻车后续**不算重复，但备注里要写清这次的差异角度。

⚠️ **没撞的也要留痕**：判「不重复」时，把「查了哪几源、没撞」一句话记下来。不写，下次就分不清它是「查过没撞」还是「压根没查」——而信息差那一维正是吃这句话。

## 撞题实证（信息差 ≥4 的唯一凭据）

按总分降序取前几个候选，逐个做：

- 搜工具名 + 搜「工具名 实测」，看中文平台有没有人真跑过。
- 搜索时可以搜大小写变体防漏检；发布时只用官方那一种唯一写法。
- 证据要记**数量 / 热度 / 最近日期 / 检索口径**四项，不是一句「搜了没有」。

三种结果：

- 国内已有人实测且讲透了 → **淘汰**，理由写一句话。
- 只有转述、没有实测 → 信息差可给 4–5，证据附上。
- **拿不到证据** → 信息差降到 ≤3 重算总分。**降分要连着证据字段一起改，别只在心里降。**

顺带一件事：检索时会撞见同题的高互动内容——**当场记进你的对标库**，别攒到周末。攒着就丢。

## 漏斗任务轴（与体裁正交，别只堆实测）

每个候选另标一个任务：**搜索 / 信任 / 互动 / 证明 / 转化 / 留存**。

只堆实测（＝信任、证明）会曝光高但涨粉弱。定选题时查一眼配比健康度，写稿时按任务落笔——搜索题要含关键词，互动题结尾的问题要更尖。
