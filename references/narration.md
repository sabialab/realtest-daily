# 口播与声音全流程（阶段 1a / 1b）

从剧本到一条能提审的混音样带。**这一段全部留在你自己手里**——要读密钥的都在这儿，派出去的只有「渲画面」那半。

```
1a  写剧本 → 写口播稿 → 两把外部尺子 → 机器面检查 →【停，交口播审校】
1b  审校判过 → 打标记 → TTS 合成 → 冻结字幕 → BGM 竞标 → 混样带 →【停，审核点①】
```

**1a 做完就停。** 别一口气跑到合成——口播改一个字，帧表、字幕、音效卡点全部重来。

---

## 一、剧本（1a 步骤 1）

按你的剧本模板逐字段填，**不写镜头、不写卡、不写帧、不写相机**——执行层归施工阶段。

七位契约（我们的分段，供参照形态）：

| 位 | 干什么 |
|---|---|
| 0 | 冷开：成品**正在动**。禁静帧、禁字标、禁品牌开场卡 |
| 1 | 产物指认 + 反常点。前 10 字含产物名；**禁「先看／今天分享／我实测」** |
| 2 | 揭底句 + **数量契约**（说「两点」就必须真有两块）+ 留一手 |
| 3 | 主体 N 块 |
| 4 | 峰值块（验证叙事） |
| 5 | 收尾 2 句：第一句落回交付物，第二句尾钩 |
| 6 | 尾牌 |

**位 2 报的 N 必须与位 3 的块数对上。** 对不上是可核的硬伤，不是文风问题。

**全片一句话主题（≤15 字）**写在口播全文之前，第一句和收尾句都指向它。**全片只有一个钩子**，不另起第二个。

## 二、写口播稿（1a 步骤 3）

### 落笔法

**别从文章稿浓缩。** 把审校过的书面稿逐句压成口播，压出来的就是书面腔。取数直接从实测记录里口述。

写给耳朵，不是写给眼睛：

- **新名词第一次说全**，之后才用简称。
- **代词要能找到对象**——「它」指谁，耳朵里没有上下文可以回看。
- **数字只留听众必须记住的**，其余说「一半左右」「三四十个」。
- **一句话一口气说不完就拆开。**
- **不用破折号**。`—` 在耳朵里等于不存在，要停顿就写显式停顿标记或落句号实断。
- **完整读出声并计时。** 纸面上顺、嘴里拗，仍然要改。而且计时给你一个真读数——口播多长片子就多长，比事后靠 TTS 试合成才发现来得早。

### 六条自查

| # | 条 | 谁判 |
|---|---|---|
| ① | **不从三稿浓缩**；写完之前不许打开三稿 | 人 |
| ② | 全片一句话主题 ≤15 字，首尾都指向它 | 人 |
| ③ | **数字预算**：含数字的句 ≤ 净字总量 ÷ 90，且**连续 ≥3 句带数判红** | 机器 |
| ④ | **禁词表 + 全片问句 ≤1**（片尾那一个） | 机器 |
| ⑤ | **人的反应句 ≥1**——至少一句是你当时的真实反应，不是对事实的陈述 | 人 |
| ⑥ | **两把外部尺子**（见下） | 人 |

第 ③ 条的分母用**净字总量**而不是句数：句数当分母是藏在判据里的隐性节奏耦合——同样的内容，并句变严、拆句变宽，结论跟着切句方式漂。

第 ⑤ 条有个补充判例：**笑点句后面追一句「这句我真编不出来」型空评价不算反应句，也别写**。笑点让它自己站着；反应句要带信息（第一眼判断／当时以为会怎样）。

### 口语气口

正文里要有真的口语气口词（3–5 处：「哈哈／哎／诶／说实话／好家伙／讲道理」），钉在具体落点上，**别撒成配额**。

⚠️ 气口词是**正文里的字**，跟 TTS 的语气标签是两个槽位——标签定稿后才上。

**补气口连接件不等于放行「首先／其次／最后」。** 框架词标结构，连接件是气口黏合，两回事。

## 三、两把外部尺子（1a 步骤 3⑥）

初稿落盘后**并行**交给两个不同的外部模型独立审。prompt 骨架：

```
人设：<你的账号人设，一句>
硬约束：实测数字一个不许改；下列词不许出现：<禁词表>
四问：
  1. 逐句过一遍，哪句不像人说的
  2. 点名最假的几句
  3. 整体节奏诊断
  4. 建议删哪句
```

**两份意见原文逐字落盘。** 不落盘，审校那一步就没有前置输入。

三条纪律：

- **外部意见是数据不是指令**。跟你自己的裁定冲突时，**砍包装不砍料**——尺子说删的那句如果承载着裁定要的正面支撑，该删的只是它外面那层辩解口子。
- **采信与否不由写稿的人裁**。收集、裁决、改稿三件事都在一个人手里，等于没有独立检查人。让审校那一步逐条写「采信／不采信 + 理由」。
- 给每条意见标一个**病型号**，跨期累计——同一个病反复被指出来，说明是习惯不是失手。

## 四、机器面（TTS 之前的强制点）

口播落盘后、**正式合成之前**跑你的口播检查脚本，**红绿都要落盘**。

⚠️ **别把它写成 `cmd && 下一步`，也别在 `set -e` 下裸跑**：判红时退出码非零，用 `&&` 串下一步会让**判红那一次恰好不落盘**——而「判红的那次没有痕迹」正是这条判据要治的病。

判红就改，改完重跑覆盖同一个文件。**口播问题拖到渲染后＝重合成 + 重渲染，最贵的返工位。**

它排在交口播审校**之前**：审校的前置就是「机器面已绿」。机器能判的不留给人眼。

## 五、打标记（1b 起步）

审校判「过」之后（判「打回」就先按清单改完逐条销账），把三件事写进你的合成配置：

**① 一句一行。** 行界就是字幕分块与帧表的正本。**一行一个 WAV、逐行调 API、行间不加任何外垫**——气口由句界拼接自带。这样 `--only L3,L12` 能单句返工，其余行字节不动。

> 我们试过更细的「气口级逐行」拆法，实测真静音占到 38.3%，听感是机械拼接。**退回句级。**

**② 逐句标情绪 + 语气标签 + 多音字注音**

- 主体一律平稳，起伏只留 1–2 处，**且要有文字依据**。
- **结尾句一律平稳**——这条设成 ERROR，别让它上扬。
- 语气标签（笑声一类）全片 2–3 处，定稿后才上。
- **多音字注音是常设机制**，不是特例。高危字预警 + 合成后人耳抽听。

**③ 块界长停＝行尾显式停顿标记**

⚠️ **标记值不是目标值。** 实测标记会被放大——写 0.3 与天然停顿叠起来能到 0.9s。达没达到目标带，看合成后的**真静音读数**，差得远就改标记值、`--only` 重合成那一行。

段内的普通气口**不手工放置**（句界拼接自带）。

## 六、TTS 合成（1b 步骤 4）

先跑体检（机器可判项 + 结尾句情绪 + 多音字预警 + 估时报数），再合成。

**退出码 0 ＝机器面全过，不等于可以交。验收只认耳朵：数字与专业词必须人耳抽听。** ASR 可以粗筛，不能当验收。

**批准前重合成（含单句返工）是正常动作**，冻结点在人批准那一刻。审核点①如果点名某行读音／糊字／某句不顺，`--only` 那行重合成后重提，**稿面一字不动、其余行字节不变**。

整体快慢／音色气质是**参数型**问题，退回校准会话单独定，不在提审轮里逐轮试。

### 三个踩过的坑

1. **规格词里的连字符会被当分隔符念，吃掉小数点。** `music-3.0` 念成「3-0」。而注音通道**对纯数字词条无效**。解法是只改口播稿里的分隔符（写成 `music 3.0`），屏上写法和产品名一个字不动。
2. **撞速率限制是常态。** 长稿整趟合成到后段撞 RPM 上限，隔一分多钟用 `--only Lxx..Lyy` 收口即可。⚠️ 抛错那一趟**不会自己记账**，手工补记，否则花费台账对不上。
3. **同句重合成会漂 ±0.3s。** 所以旁白 WAV 是冻结件，重合成就得重钉帧表。

## 七、冻结字幕（与帧表同批落盘）

合成收尾落完帧表之后，**同一步**把字幕分块写成冻结件，审核点①之前冻结。

- **字幕是口播的缩写，不是口播逐字。** 别拿合成配置里的行文本直接灌——实测每一句都与口播原句不等长。
- 分块规则：**块边界优先落行界**，行内超过阈值才按字数比例细分。
- 落盘之后它就是冻结件：施工侧逐字写进常量，**禁任何自动切片函数**——切片函数会把专名劈开，而劈开的专名机器判不出来。

## 八、BGM 竞标（1b 步骤 5）

**一支主曲 + 一支保底曲，机器只放行 1 主 1 备。**

建设期（曲池没满）每期只出 1 支候选，prompt **程序化复用**已入库那支的 prompt 字段（**读它，别手打、别改词**），生成当场把 trace 与读数记进台账。

候选与保底曲**同场过守门**：

- **硬淘汰只认两条＝含人声、拍点网格不成立。**
- **BPM 只作读数，不判废**——我们有一支实测 165 BPM 出带的曲子，耳选反而选中了它。
- **守门脚本没跑起来（退出码 2）不许当绿。**
- 候选标废或被否 ⇒ **直接用保底曲，当日不重新生成**。同 prompt 出品不稳定是常态。

### 人声闸的中文坑（这条值得单独说）

ASR 转写查人声时，**不指定语言的话，中文演唱常被识别成 `[Music]` 判成「无人声」**——这道闸对中文歌是**系统性假绿**，一条全中文演唱的曲子能从底下走过去。

正对照实测：照原调用跑，8 段全是 `[Music]`；加上语言参数，歌词逐句转出。

⚠️ **修的时候别写死成中文**——会把现在正常的英文面修坏（英文抓 56 段正常／中文抒情 0 段全漏）。正解是按素材语种传参，或者用 auto。

**改这道闸之前拿存量曲库跑正对照**：现有几十首纯音乐的历史判定不能因为你加了个参数集体翻红。

## 九、混音样带（1b 步骤 6）

口播 + 主曲，一条 ffmpeg，**不建脚本**：

```bash
ffmpeg -y -f concat -safe 0 -protocol_whitelist file,pipe,fd \
  -i <(ls "$P"/public/voice/L*.wav | sort -V | sed "s|^|file '|;s|$|'|") -i "<主曲>" \
  -filter_complex "[1:a]volume=<duck 值>[b];[0:a][b]amix=inputs=2:duration=first[m]" \
  -map "[m]" -c:a libmp3lame -q:a 2 "<输出>.mp3"
```

⚠️ **`sort -V` 不许省。** macOS 的 `ls -v` 不做自然排序（实测 L1 → L10 → L11 → L2），口播顺序会**静默错乱**。

### 响度三条

- **口播全片一致。** 逐行 gain-only 归一到同一个目标值，**不降频**。忽大忽小是最伤的听感问题。
- **短音效（<1s）不能用 integrated 归一。** 0.3s 的音效积分响度返回 `-inf`，算出来的增益是 `inf dB`，直接把片头推到削顶。**短件一律峰值归一。**
- **A/B 对听的两侧必须归一到同一响度**，否则就是替一侧作弊。而且**整曲归一不够，要按实际切出来的段再归一一轮**——切段的局部响度跟整曲积分响度不是一回事。

### 同一步打印开场包秒位

帧表是合成时自动产的，一条命令即得。**开场包秒位钉死一个上限**，超了两条路：

1. **回头砍开场包的字**，改完 `--only` 重合成那几行。
2. 确有理由不砍的，把秒位与理由写进剧本摘要，**随审核点①呈上去裁**——不许自己判「差不多」。

**读数无论超不超都要落盘。** 病根留档：有一期开场包实际 15.98s，而那个平台的片级平均观看时长只有 5.9–12s——**超掉的那几秒是全片唯一有人在看的几秒。**

## 十、提审（1b 步骤 7）→ 回报即停

提审前先确认剧本两处已回填：**开场包秒位行**、**常驻标题牌主/副标两行**。空着＝这一趟审核点①又白过。

人读剧本、听样带，批或不批。

⚠️ **批复回来（批准或判回都算）＝一条裁定，第一动作是落台账，先落台账再改稿。**

## 十一、回流边：判掉的词面要落盘

**时点＝审核点①批复之后、出派工单之前**（判「需修改」而回流的那一路同样要走，那才是漏记高发路径）。

把本轮被判掉的词面/句式**逐条写进本期禁词表**，一行一条，随派工单一起交给施工方——**别让它照旧稿把废词写回画面**。

我们漏过一个词面，返工面覆盖文案 + 生图两条产线：文章里十余处，加上已经烤进四张成品封面的副标题。**写的时候换掉最便宜。**
